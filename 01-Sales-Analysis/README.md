# 📊 Sales Analysis | Data Analytics Project

## 📌 Descripción

Este proyecto tiene como objetivo analizar los datos de ventas de una empresa para identificar tendencias, productos destacados, comportamiento de los clientes y oportunidades de mejora.

El análisis permitirá transformar datos de ventas en información útil para apoyar la toma de decisiones del negocio.

## 🎯 Objetivos

- Analizar el comportamiento de las ventas.
- Identificar los productos con mayores ingresos.
- Detectar los clientes más importantes.
- Analizar las ventas por región.
- Identificar tendencias mensuales.
- Calcular indicadores clave de rendimiento (KPIs).
- Construir un dashboard interactivo en Power BI.
- Generar recomendaciones basadas en datos.

## 🛠️ Herramientas

- Excel
- Power Query
- SQL
- Power BI
- DAX

## 📊 KPIs

Durante el proyecto se analizarán indicadores como:

- Ventas totales
- Ganancia total
- Cantidad de pedidos
- Ticket promedio
- Producto más vendido
- Categoría con mayores ventas
- Cliente con mayor facturación
- Región con mayores ventas

## 🔄 Proceso del proyecto

1. Obtención del dataset
2. Exploración inicial
3. Limpieza de datos
4. Transformación de datos
5. Análisis con SQL
6. Creación de KPIs
7. Desarrollo del dashboard en Power BI
8. Obtención de insights
9. Recomendaciones de negocio
